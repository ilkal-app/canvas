# Security policy

## Reporting a vulnerability

Please report security problems privately, by email to
[support@ilkal.app](mailto:support@ilkal.app), with "Security" in the subject. Do not open a
public issue, discussion or pull request for a vulnerability.

Include what you can of:

- the affected version or commit;
- what an attacker can do, and the steps to reproduce it;
- a proof of concept, if you have one.

## What happens next

- **Within 3 working days** we acknowledge your report.
- **Within 10 working days** we tell you whether we accept it as a vulnerability, and what we plan
  to do.
- We keep you informed while we work on a fix, and agree a disclosure date with you. We aim to
  release a fix within 90 days of your report.
- With your permission, we credit you in the release notes.

## Supported versions

Until 1.0, only the latest release of `@ilkal/sdk` receives security fixes.

## Scope

This policy covers the code in this repository and the `@ilkal/sdk` package on npm. Problems in
the hosted Ilkal service at ilkal.app can be reported to the same address.
