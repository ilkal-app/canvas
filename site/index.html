An infinite canvas for your app

@ilkal/sdk puts an infinite canvas in any web page: shapes, text, sticky notes, frames, pens and connectors, drawn on the GPU. It is the canvas Boards is built on, open source under the Apache License 2.0. 

import { mount } from '@ilkal/sdk';

const canvas = await mount(document.getElementById('board')!, { theme: 'system' });

Local first. Version 0 keeps the board in the page, in memory or on the device. It makes no network request of its own. Real-time collaboration comes in a later release.

One command layer. Your code changes the board through the commands the editor's own tools use. Each is checked against the board and applied in one undo step, or refused whole. Run a command as the person at the board, or as an agent working beside them: undo takes either back.

Events. Listen for changes, the person's selection and errors, all typed.

Your look. Light, dark or the system's theme, changed while the canvas runs, and your own fonts for its toolbar and panels.

  • Install: npm install @ilkal/sdk react react-dom
  • Source, issues and contributing: github.com/ilkal-app/canvas
